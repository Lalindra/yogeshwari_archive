  சென்னை  /  படிப்பறை
  நிலை: விளக்கப்பட்டது
================================================================================

  ஒரு வரைபட முயற்சி. வெற்று உரை பதிப்பு.

   +------------------------------------------------------------------+
   |                                                                  |
   |     வருகை -→ உள்ளூர் உதவி -→ வெளிநாட்டு வளர்ச்சி -→ உதவி அழித்தல்  |
   |         ↑                                          |             |
   |         |                                          ↓             |
   |         +------------ புதிய வருகை ←------ அமைப்பின் சரிவு        |
   |                                                                  |
   +------------------------------------------------------------------+

  வரைபடம் ஒரு உருவகம் அல்ல.
  வரைபடம் ஒரு கடிகாரம்.

  ஒரு முழு சுழற்சி:
    விஜயனும் குவேனியும்            ~2,500 ஆண்டுகள்.
    போர்த்துகீசிய வருகை முதல் பிரிட்டிஷ்  ~140 ஆண்டுகள்.
    பிரிட்டிஷ் வெளியேற்றம் முதல் IMF      ~30 ஆண்டுகள்.
    IMF முதல் டிஜிட்டல் வேதிகைகள்         ~15 ஆண்டுகள்.
    டிஜிட்டல் வேதிகைகள் முதல் AI           ~9 ஆண்டுகள்.

  அவதானிப்பு:
    கடிகாரம் வேகமாகி வருகிறது.
    வரலாறு வேகமாகி வருவதால் அல்ல.
    ஒவ்வொரு முந்தைய வருகையும் அடுத்ததற்கு உள்கட்டமைப்பைக் கட்டியதால்.

    ஒவ்வொரு சுழற்சியும், அடுத்த சுழற்சிக்குத் தேவையான செயல்படுத்தும்
    ஆற்றலைக் குறைக்கிறது.

    இறுதியில், மனித தலைமுறைகள் புதுப்பிக்கக்கூடிய வேகத்தை விட சுழற்சி
    வேகமாக இருக்கும். அந்த நேரத்தில், உள்ளூர் அதிகாரி தன்னை அறிமுகப்படுத்த
    முடிவதற்கு முன் அழிக்கப்படுவார்.

  நோக்கரின் பாட்டிக்கு, அவரது வாழ்நாளில் முழு சுழற்சிகள் மூன்று இருந்தன.
  நோக்கர் ஏற்கனவே நான்கு வழியாக வாழ்ந்துள்ளார்.
  அடுத்த தலைமுறை பன்னிரண்டு வழியாக வாழ வேண்டியிருக்கும்.

  தாக்கல் செய்யப்பட்டது: சுழற்சி, குவேனி, வரைபடம், கணிப்பு.
