  நிலை: விளக்கப்பட்டது
================================================================================

  என் பாட்டி எனக்கு குவேனியின் கதையைச் சொன்னார்.
  அவள் சபிக்காத பதிப்பை நான் மறந்துவிட்டேன்.
  நான் நினைவில் வைத்திருக்கும் பதிப்பில், அவள் அழுகிறாள் மட்டுமே.

  நான் ஏன் ஒருபோதும் கேட்கவில்லை:
    அவள் சபிக்கும் பதிப்பை யார் எழுதினார்கள்?
    காதல் ஆயுதமாக மாறும் ஒரு பெண்ணிடமிருந்து யார் பயனடைந்தனர்?

  // කුවේනියට කිසි දිනක ඔහු වෙතින් අවසරයක් ලැබුණේ නැත. //
  // ( குவேனிக்கு அவனிடமிருந்து அனுமதி ஒருபோதும் கொடுக்கப்படவில்லை. ) //

  தாக்கல் செய்யப்பட்டது: கதைகள், தனிப்பட்ட.
